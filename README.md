# Final Project

## Overview
This project is an AI-powered Emotion Detection web application built using Python, Flask, and the Watson NLP library. It allows users to input text statements and analyzes the text to determine the emotional breakdown (anger, disgust, fear, joy, and sadness) along with the dominant emotion.

## Features
- **Emotion Analysis:** Integrates with the Watson NLP library to predict emotions from text.
- **Web Interface:** A Flask-powered web server paired with an interactive HTML/JavaScript frontend.
- **Error Handling:** Validates inputs and handles blank or invalid entries gracefully.
- **Unit Testing:** Automated unit testing using Python's `unittest` framework.
- **Static Code Analysis:** Maintained code compliance using Pylint.
